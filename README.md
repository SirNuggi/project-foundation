# Golf Buddies Live

Ich möchte eine mobile Web-App für Golfer erstellen, um Runden live mit Freunden zu tracken und ein spezielles Strafpunktsystem zu nutzen. Bitte plane und erstelle die App Schritt für Schritt. Verwende Supabase für die Datenbank.

Bitte starte JETZT mit SCHRITT 1 (Log-In & Dashboard):

- Erstelle ein sauberes, modernes Mobile-First-Design (optimiert für Smartphones auf dem Golfplatz).

- Implementiere ein einfaches Registrierungs- und Login-System.

- Erstelle ein Dashboard mit zwei Haupt-Buttons: "Neue Runde starten" und "Statistiken".

- Wenn man auf "Neue Runde starten" klickt, soll man den Namen des Golfplatzes eingeben und über eine Spielersuche/Liste Freunde (Mitspieler) zu dieser Runde hinzufügen können.

WICHTIG FÜR DIE ZUKUNFT (Bitte im Code und in der Datenbankstruktur bereits im Hintergrund vorbereiten, aber noch nicht visuell bauen):

- Jede Runde wird ein Live-Leaderboard haben, bei dem man pro Loch die Schläge und Putts einträgt.

- Es wird ein Strafpunktsystem geben (automatisch berechnet bei 3-Putts oder Doppel-Par; manuell anklickbar für Sonderstrafen wie "Girly").

- Die Daten müssen dauerhaft für Langzeitstatistiken pro Spieler in der Datenbank gespeichert werden.

- Später fügen wir eine GPS-Live-Karte für die Positionen der Spieler hinzu.

Bitte baue zuerst nur das funktionierende Dashboard mit der Spieler- und Rundenanlage (Schritt 1) und zeige mir die Vorschau.
